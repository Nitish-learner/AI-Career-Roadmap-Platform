Inheritance

Understand how inheritance allows one class to acquire the properties and behaviour of another class.

Lesson Progress 0%

What is Inheritance?

Inheritance is one of the important concepts of Object-Oriented Programming. It allows a new class to reuse properties and methods of an existing class.

Simple Definition

Inheritance means creating a new class from an existing class.

Why do we use Inheritance?

  • Code reusability
  • Reduces duplicate code
  • Supports method overriding
  • Makes applications easier to maintain

Java Example

In Java, the extends keyword is used to create inheritance.

Java 
class Animal {

    void eat() {
        System.out.println("Animal is eating");
    }
}


class Dog extends Animal {

    void bark() {
        System.out.println("Dog is barking");
    }
}


public class Main {

    public static void main(String[] args) {

        Dog dog = new Dog();

        dog.eat();
        dog.bark();
    }
}
