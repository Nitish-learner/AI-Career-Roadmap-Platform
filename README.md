# 🚀 CareerAI - AI Career Roadmap Platform

CareerAI is an AI-based career preparation platform designed to help students choose a career path, follow a structured learning roadmap, practice skills, complete assessments, and track their career readiness.

## ✨ Features

- 🔐 User Registration and Login
- 📊 Interactive Dashboard
- 🎯 Career Selection
- 🗺️ Personalized Career Roadmap
- 📚 Learning Modules and Lessons
- 💻 Practice Section
- 📝 Assessments and Quizzes
- 📁 Projects Section
- 📈 Learning Progress Tracking
- 🎯 Career Gap Analysis
- 👤 User Profile Management
- 📊 Career Readiness Score

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MySQL
